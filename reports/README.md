# Evaluation reports

`current/core_accuracy.json` records the current classifier measurement and regression gate results. Its external companion reports and `core_removal_parity.json` are described in [the baseline](../docs/baseline.md).

Other dated reports retain earlier detector/corpus measurements and label provenance. `layer-attribution/` contains candidate miss analysis. Product-service latency reports were removed along with the services; previous versions remain in Git history.

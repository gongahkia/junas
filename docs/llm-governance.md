# Advisory experiments

The default classifier is deterministic. `audit_grade` experiments can add public-evidence retrieval, structured LLM adjudication, defined-term extraction and coverage warnings when explicitly configured.

Deterministic findings and scores control `overall_risk`. Coverage warnings and defined-term proposals remain unverified advice in `coverage_warnings`; adjudication remains unverified advice in `llm_adjudication`. They cannot add findings, suppress names, or replace the scored risk. There is no verified-AI detector or acceptance path in this tranche. Model-suggested public status and sources are proposals, not verified claim-level evidence. Retrieved source candidates also do not establish that each document claim is public.

Adjudication, coverage audit and retrieval retain the existing `audit_grade` MNPI band gate `[25, 70)`, evaluated before conjunctive MNPI scoring. Consequently, PII-only documents do not engage those components. Defined-term extraction is a separate `audit_grade` pre-pass, including for PII-only documents when configured. `audit_grade` also retains its existing deterministic quasi-identifier behavior without an AI provider. It is not equivalent to strict with additional AI advice.

Successful model advice carries provenance and explicit unverified/advisory markers. Malformed model output and configured-helper failures cause an explicit error, rather than a valid-looking fallback classification. Standalone helper utilities retain their documented optional fail-open mode; the review engine calls them with `fail_closed=True`. Keep strict and assisted measurements separate. Mocked behavior checks do not establish model accuracy.

Remote endpoints require explicit permission in configuration. Remote raw text additionally requires an explicit raw-text opt-in; structured tokens are the remote default. Provider-specific opt-in checks remain in the retained clients. Standard tests mock transport and do not send corpus text to providers.

Structured adjudication hashes caller entity identifiers, validates exact source bounds and text locally, and sends only closed-vocabulary finding metadata, context hashes and aggregate retrieval counts. Coverage audit sends closed metadata and a body hash, with no source spans or free-form detector reasons. Hashes allow linkage and are not anonymity guarantees. Defined-term extraction sends up to 2,000 preamble characters and therefore requires the remote raw-text opt-in even when adjudication uses structured tokens. Existing public search uses the separately configured query sanitizer; it is not covered by the structured-token contract.

Defined-term cache v2 includes document hash, provider, model, prompt version/hash, endpoint, implementation and configuration/credential-scope fingerprints. Runtime permission checks apply before cache reuse. Legacy document-only entries are ignored; unattributed injected extractors run without disk caching. These identities attribute configuration, not immutable hosted model weights. Caches and teacher-call ledgers are research artifacts under `JUNAS_CACHE_DIR`.

Before promoting an advisory model, use independently reviewed labels, compare precision and recall with the deterministic baseline, inspect false positives and misses, and run `training/distillation/promotion_gate.py`. Training data must not overlap a claimed held-out test. See the [T4A integrity report](../reports/current/T4A_REPORT.md) for compatibility changes and verification.
